الحوسبة: الاختبار العملي

مراجعة عملية ليوم الأحد ٢٢ نوفمبر – Audacity وEdge وClipchamp

اختبار الحوسبة العملي

الاختبار العملي يوم الأحد ٢٢ نوفمبر ٢٠٢٦، وفيه ٣ أسئلة:

  1. Audacity (أيقونة سماعة رأس زرقاء) – فتح صوت وتحديد جزء ودمج صوتين.
  2. Microsoft Edge (أيقونة الحرف e) – البحث عن صورة للدوحة وحفظها.
  3. Microsoft Clipchamp (أيقونة بنفسجية) – إنشاء فيديو من الصورة والصوت.
خطوات الحفظ (في الأسئلة الثلاثة)
احفظي دائماً في: سطح المكتب ← مجلد الصف الرابع ← مجلد رابع ١ (قد يظهر باسم 4-1).
اسم الملف: اسمج الأول (دانة)، ثم Save.
واجهة البرامج بالإنجليزي، والخطوات من فيديو مراجعة المعلمة. اقرئي «أتعلّم» ثم تدرّبي في «أتدرّب».

١. السؤال الأول: Audacity

البرنامج: Audacity 3.4.2 – أيقونة سماعة رأس زرقاء، والواجهة بالإنجليزي.

  1. انقري نقراً مزدوجاً على أيقونة Audacity.
  2. اختاري File > Open.... الاختصار Ctrl+O.
  3. روحي إلى سطح المكتب ← الصف الرابع ← رابع ١ (أو 4-1)، اختاري الملف الصوتي «أنا قطري» (mp3)، ثم Open.
من فيديو مراجعة المعلمة: قائمة File وخيار Open... (Ctrl+O)
  1. التحديد: اضغطي زر الفأرة الأيسر واسحبي على الموجة الزرقاء لتحديد جزء منها. الجزء المحدد يصير أبيض (أو فاتح).
  2. التشغيل: اضغطي المثلث الأخضر أو مفتاح Space (المسافة).
لاحظي الجزء الفاتح/الأبيض على الموجة: هذا التحديد
  1. دمج الأصوات: اختاري File > Import > Audio... (الاختصار Ctrl+Shift+I)، ثم اختاري «أنشودة قطر» واضغطي Open. الحين يظهر عندج ملفان صوتيان فوق بعض.
File ثم Import ثم Audio... (Ctrl+Shift+I) بعد الاستيراد: ملفان صوتيان (أنا قطري وأنشودة قطر) والجزء الأبيض باقٍ
  1. الحفظ: اختاري File > Save Project > Save Project As...، روحي إلى مجلد رابع ١، اكتبي اسمج الأول، ثم Save.
File ثم Save Project ثم Save Project As... – مو Export نافذة الحفظ: النوع Audacity projects (*.aup) ومجلد الصف الرابع
أهم نصيحة المعلمة: «لازم أحصل عندك ملفين صوتيين والجزء الأبيض».
يعني قبل الحفظ لازم تشوفين الملفين فوق بعض، والتحديد الأبيض ظاهر. احفظي بـ Save Project As...، مو Export.

٢. السؤال الثاني: Microsoft Edge

  1. انقري نقراً مزدوجاً على أيقونة Microsoft Edge (الحرف e).
  2. اكتبي في شريط البحث كلمة قطر، ثم اضغطي Enter.
  3. افتحي تبويب Images (الصور)، ثم انقري على صورة للدوحة.
بعد البحث عن «قطر»: تبويب Images وصور الدوحة. إذا ظهر مربع ترجمة، تقدرين تقفلينه
  1. اضغطي زر الفأرة الأيمن على الصورة، ثم اختاري Save image as.
  2. روحي إلى سطح المكتب ← الصف الرابع ← رابع ١، اكتبي اسمج الأول، ثم Save.
بعد زر الفأرة الأيمن: اختاري Save image as

٣. السؤال الثالث: Microsoft Clipchamp

  1. اضغطي Start (ابدأ)، ثم ابحثي عن Clipchamp وافتحيه (الأيقونة البنفسجية).
  2. اختاري Create new ثم Blank Video.
Create new ثم Blank Video
  1. في أعلى اليسار، غيّري عنوان المشروع إلى قطر ثم Enter.
  2. اضغطي الزر البنفسجي Import media، اختاري الصورة اللي حفظتيها في السؤال الثاني، ثم Open. اسحبي الصورة إلى شريط الزمن (المكان المكتوب فيه Drag & drop media here).
  3. مرة ثانية Import media، اختاري الصوت «أنا قطري.mp3»، واسحبيه تحت الصورة على شريط الزمن (مكان + Add audio).
الصورة على شريط الزمن، والصوت «أنا قطري.mp3» جاهز تسحبينه تحتها على Add audio
  1. اضغطي Export واختاري الجودة 1080p، ثم انتظري حتى يجهز الفيديو.
  2. بعد ما يجهز، اضغطي Save to your computer، روحي إلى مجلد رابع ١، اكتبي اسمج الأول، ثم Save.
Export video: اختاري 1080p ثم Export بعد التجهيز: لازم تضغطين Save to your computer
نصيحة المعلمة: Export لحاله ما يكفي. لازم بعد ما يجهز الفيديو تضغطين Save to your computer وتحفظينه في مجلد رابع ١ باسمج.

كلمات مهمة

احفظي هالكلمات، تجين في الخطوات:

  • سطح المكتب (Desktop): الشاشة الأساسية للكمبيوتر، ومنها نفتح مجلد الصف الرابع.
  • زر الفأرة الأيسر: نستخدمه للتحديد (مثل تحديد الجزء الأبيض على الموجة) وللضغط العادي.
  • زر الفأرة الأيمن: نستخدمه لفتح قائمة، مثل Save image as لحفظ الصورة.
  • مجلد: مكان نحفظ فيه الملفات، مثل مجلد رابع ١.
  • تحديد: اختيار جزء من الموجة الصوتية، فيصير أبيض.
  • دمج الأصوات: جمع ملفين صوتيين في Audacity عن طريق الاستيراد.
  • استيراد (Import): إدخال ملف صوتي أو صورة إلى البرنامج.
  • حفظ كمشروع (Save Project As...): طريقة الحفظ الصحيحة في Audacity (مو Export).
  • شريط الزمن (Timeline): الشريط السفلي في Clipchamp، نسحب عليه الصورة والصوت.
  • إنشاء فيديو (Create new ثم Blank Video): بداية مشروع جديد في Clipchamp.
